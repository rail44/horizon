# 第十六巡：実際の変更による保守性の比較

boardを除く4系統で試験機能を実装し、構造を見直した後に**同じ変更を再実装**した。
基準は `73e22446`、本実装は `7d289bca`。[確認範囲](../../scripts/refactor-audit/coverage-change-probes.json)は24ファイル。

| 試験変更 | 本体の変更ファイル数（前→後） | 結果 |
| --- | --- | --- |
| fs.readに読取り文字数指定と結果表示を追加 | 3→3 | 定義・実行・表示は別の判断。承認対象の分類と実行経路は変更不要で、構造を維持 |
| 既存のフォントサイズ初期化をCLIに公開 | 3→3 | CLI内の送信名の定義を**2か所→1か所**に統一。キー・パレット・実行処理は既存のCommandIdを利用 |
| フォントサイズの変更幅を設定し、reload可能にする | 5→5 | 警告一覧への追加漏れが、従来のテストでは通過→**恒常テストで失敗**。読込み・値の検証・適用の責務は維持 |
| toolの入れ子errorを失敗と解釈する | 1→1 | 結果の構築1か所の変更が、実行中の表示・保存・復元・検索へ伝わる。構造を維持 |

mainに入れた変更は、CLI送信名の重複除去と、設定診断の整合性チェック。
後者はserdeが受理するフィールド名と8つの警告用一覧を照合するテストで、実行時の仕組みは増やしていない。
そのテストで既存の `mach_services` の誤警告も検出し、修正した。権限の解釈・付与は変えていない。

試験機能は `probe/changes-before`（`4e654c5a`）と `probe/changes-after`（`032e165`）に保持し、mainには含めない。
[試験条件・結果・再実行手順](../../scripts/refactor-audit/change-probes.json)にコミットとテスト名を記録した。
前後の試験差分も照合し、CLIの送信名取得以外は同一であることを確認した。
ファイル数や複雑度の減少を成果とはしていない。

試験6件は前後とも成功。変更漏れを意図的に作ると、schema漏れ・CLI名の不一致・結果解釈漏れを検出した。
設定の恒常テストは、新設の試験テストを除いても追加漏れを検出する。
agentはJSONLへの実書込み、復元、DuckDBの履歴・検索、投影の再構築まで検証した。外部providerは呼んでいない。
fs.readはroot内外の分類と承認済み／自動実行を検証し、人の承認画面は操作していない。

隔離X11環境では、キーによる拡大・CLIによる初期化・設定reloadを前後とも実行。
PTYの行列数は **34×130 → 29×113 → 初期化34×130 → reload後26×101** と一致した。
統合したmainでも端末frameの色・OSC8・文字、2タブと分割・同じ3セッションの復元、実キー入力を確認した。
利用者のアプリ・daemonは再起動していない。画素単位の見た目、Wayland・物理IME・他OSの実動作は未検証。

mainのfmt・Clippy・sandboxed nextest **2,082件**・default nextest **2,231件**・wire・WASM library・workspace buildは通過。
通信・保存形式、依存関係、boardの除外33構文片と専用分岐は不変。
最終clean mainの互換条件で本体・テストを再解析し、対応不明の追加・削除・曖昧な識別子は0。
本体は **346ファイル／2,382関数**で不変、テストは **263ファイル／2,728→2,733関数**。
clone pairsは本体221・テスト998で不変。維持判断17件のうちCLIに関連する根拠1件を更新し、全件有効。
[本体](../../scripts/refactor-audit/correspondence-change-probes.json)・[テスト](../../scripts/refactor-audit/correspondence-change-probes-tests.json)各1組を対応付けた。
