## fs.patch が使われない機構（修理不能ではないが採用実績が壊滅）

- repo 全体で **6 回試行 5 回失敗**（3,826 call 中）。
- 根因: `@@` ヘッダを「近傍ソース行の literal アンカー」とする
  V4A 意味論なのに、**スキーマ記述がそれを一切説明しない**。モデルは
  訓練分布通り `@@ -1,6 +1,8 @@` を書き、必ず 0 match。エラー文
  「add more context」は誤誘導（ヘッダ不正はコンテキスト拡大で直らない）。
- fs.edit の記述から fs.patch への導線もない（発見性の非対称）。
- 権限差はなし（両方 RequireApproval）。
